# AI 自动化企业网站维护助手

> 华为 ICT 大赛·创新赛·赛题一作品

## 项目简介

使用 Hugo 制作企业网站，用 CodeArts 代码智能体 + 大模型辅助维护。管理员通过自然语言提出需求，AI 按照预先设计的 Skill 和规范修改网站，经过检查和人工审核后发布。

## 核心流程

```
提出需求 → AI 修改 → 构建和检查 → 人工预览审核 → 发布
```

## 目录结构

```
ai-site-maint/
├── content/          # Hugo 网站内容（新闻、产品、页面）
├── layouts/          # 模板
├── static/           # 静态资源（图片等）
├── data/             # 数据文件
├── hugo.toml         # Hugo 配置（品牌事实源，L3 保护）
├── .harness/         # AI 维护规范体系
│   ├── AGENTS.md     # AI 操作总规范
│   └── skills/       # 网站维护 Skill
└── 00-提示词骨架.md   # 给 CodeArts 的提示词
```
